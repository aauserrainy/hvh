# Test fixtures

Two small models used only by `server/assets-e2e.js`, to prove the external
model pipeline really loads glTF rather than just claiming to. They are not
game art and are never loaded by the game itself.

From Kenney's Starter Kit FPS (https://github.com/KenneyNL/starter-kit-fps),
CC0 1.0 Universal - public domain, redistributable without attribution.
Licence text kept alongside in `KENNEY-CC0-LICENSE.md`.

They are committed deliberately, rather than left in the gitignored `assets/`
directory, so the suite passes on a fresh clone with nothing to download.
