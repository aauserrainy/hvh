HOW TO PLAY A FRIEND

  1. You: open a game and click ONLINE 1v1 (top left), then HOST A MATCH.
  2. Send your friend the room code, or press COPY LINK and send the link.
  3. Friend: opens the link (it joins automatically), or types the code and presses JOIN.
  4. When it says Connected, click the game to capture the mouse. Esc frees the mouse again.

Stuck connecting? Try Chrome or Edge, turn off VPNs, and have the host re-host. See the README for strict-network fixes.
